# Gerenciador de Tarefas

## Descrição
Uma aplicação web de gerenciamento de tarefas desenvolvida com PHP no backend, MySQL para persistência de dados, e frontend utilizando HTML, CSS, JavaScript e Bootstrap.

## Requisitos
- Docker
- Docker Compose

## Configuração e Instalação

### Passos para Executar o Projeto

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/task-management-app.git
cd task-management-app
```

2. Iniciar os serviços com Docker:
```bash
docker-compose up -d
```

3. Acessar a aplicação:
- Frontend: http://localhost:8080
- Backend API: http://localhost:9000

## Funcionalidades
- Criar novas tarefas
- Listar tarefas
- Editar tarefas existentes
- Excluir tarefas
- Alterar status das tarefas

## Tecnologias Utilizadas
- Backend: PHP 8^
- Banco de Dados: MySQL
- Frontend: HTML, CSS, JavaScript (Vanilla)
- Framework CSS: Bootstrap
- Containerização: Docker
